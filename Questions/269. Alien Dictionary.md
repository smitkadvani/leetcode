### Question
There is a new alien language that uses the English alphabet. However, the order of the letters is unknown to you.

You are given a list of strings `words` from the alien language's dictionary. Now it is claimed that the strings in `words` are **sorted lexicographically** by the rules of this new language.

If this claim is incorrect, and the given arrangement of string in `words` cannot correspond to any order of letters, return `"".`

Otherwise, return _a string of the unique letters in the new alien language sorted in **lexicographically increasing order** by the new language's rules__._ If there are multiple solutions, return _**any of them**_.

**Example 1:**

**Input:** words = ["wrt","wrf","er","ett","rftt"]
**Output:** "wertf"

**Example 2:**

**Input:** words = ["z","x"]
**Output:** "zx"

**Example 3:**

**Input:** words = ["z","x","z"]
**Output:** ""
**Explanation:** The order is invalid, so return `""`.

**Constraints:**

- `1 <= words.length <= 100`
- `1 <= words[i].length <= 100`
- `words[i]` consists of only lowercase English letters.

### Solution
```python
class Solution:
    def alienOrder(self, words: List[str]) -> str:
        # First we need to create adj set for character 
        ancesors_adj = {char:set() for word in words for char in word}
        childern_adj = {char:set() for word in words for char in word}

        for index in range(len(words) - 1) :
            word1, word2 = words[index], words[index + 1]
            l1, l2 = len(word1), len(word2)
            min_len = min(l1, l2)
            if word1[:min_len] == word2[:min_len] and l1 > l2 : 
                return ""
            for j in range(min_len) :
                if word1[j] == word2[j] :
                    continue
                ancesors_adj[word2[j]].add(word1[j])
                childern_adj[word1[j]].add(word2[j])
                break
        
        # Finding the root node with no ancestors 
        queue = deque([])
        for node, ancestors in ancesors_adj.items() :
            if len(ancestors) == 0 : 
                queue.append(node)

        res = []
        while queue : 
            for _ in range(len(queue)) :
                node = queue.popleft()
                res.append(node)
                for next_node in childern_adj[node] :
                    ancesors_adj[next_node].remove(node)
                    if len(ancesors_adj[next_node]) == 0 :
                        queue.append(next_node)
        return "".join(res) if len(res) == len(ancesors_adj.keys()) else ""
```
